报名政策

发布后，网站政策页和 CRM 报名表同步；旧订单保留家长当时同意的政策全文、版本和时间。

合作 After-School

专属报名链接自动带入机构与学期。独立课程表单可填写 HTTPS 地址；留空则进入 H-Music 注册表。

活动报名入口

活动名称、说明、日期与地点写入描述；填写报名地址后前台显示报名按钮。留空则显示“报名尚未开放”。

折扣码

折扣码单独保存后立即生效，不随网站草稿发布。订单中只允许一个折扣码。未完成支付的订单会预留使用名额；确认过期或关闭未支付订单后释放，退款不自动恢复次数。

报名付款订单

付款不自动开通家长访问或安排课表。进入对应报名审核学生资料与后续排课；下方金额为本次报名实际收款。未缴费或银行处理中均不会标记已付款。

关联已付款订单

先在报名管理中审核并创建学生档案，再选择该学生。系统按已确认付款创建账单、入账并增加对应课包课时，不会再次收费。
